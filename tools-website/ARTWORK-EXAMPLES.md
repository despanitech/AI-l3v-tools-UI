# Magic Identity card examples

The user requested attractive name, initials and signature samples inside the three category cards. These are existing generated artwork examples, not generated results for whatever name a visitor types. Cards label them “Style example” and keep the visitor's text separately below. Names on the examples are described accurately in alt text.

Original PNGs are copied without altering artwork or aspect ratio. Public inclusion of these selected generated outputs is part of the requested UI change; private reference sheets, generation prompts and service state are not included.
